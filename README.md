## Лабораторна №1 — "Пакети прикладних програм, розроблених на факультеті"

БД з 7 таблиць ([schema.sql](lab1/sql/schema.sql), тестові дані — [seed.sql](lab1/sql/seed.sql)):

| Таблиця | Що зберігає |
|---------|-------------|
| `developers` | студенти та викладачі, які розробляють ППП (категорія, група/кафедра, e-mail) |
| `packages` | пакети прикладних програм (назва, версія, галузь, опис, дата випуску) |
| `package_developers` | хто над яким пакетом працює і в якій ролі (керівник / розробник / тестувальник) |
| `rooms` | аудиторії |
| `seminars` | графік семінарів для ознайомлення з ППП (дата, час, тривалість, тема, ведучий) |
| `demonstrations` | план демонстрацій (дата, час, аудиторія, доповідач, для кого) |
| `test_runs` | план тестових випробувань (дата, вид, статус, тестувальник, примітки) |

- [Model.hs](lab1/src/Model.hs) — типи-записи для кожної таблиці та класи типів:
  - `Entity` — ім'я таблиці, стовпці, перетворення запису в параметри SQL;
  - `Display` — виведення в консоль;
  - `Editable` — введення нового запису та коригування наявного;
  - для кожного типу написані instances цих класів і `QueryResults`.
- [Db.hs](lab1/src/Db.hs) — узагальнені CRUD-операції (`findAll`, `findById`, `insertEntity`,
  `updateEntity`, `deleteEntity`) для будь-якого `Entity`, пошук і звіти:
  пакети за ключовим словом і за розробником, команда пакета, графік семінарів на період,
  план демонстрацій і випробувань на період, підсумки по пакетах.
- [Main.hs](lab1/src/Main.hs) — консольне меню; одне меню `tableMenu` працює для всіх таблиць
  (перегляд, пошук за id, введення, коригування, видалення).

```bash
mysql -u root --default-character-set=utf8mb4 < lab1/sql/schema.sql
mysql -u root --default-character-set=utf8mb4 < lab1/sql/seed.sql
cabal run lab1
```

Параметри підключення: змінні середовища `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`
(за замовчуванням `127.0.0.1:3306`, `root`, без пароля, `faculty_packages`).

## Лабораторна №2 — сортування Бетчера у k потоків

Обмінне сортування зі злиттям Бетчера (Д. Кнут, т. 3, алгоритм 5.2.2M) працює для довільного `n`.
Алгоритм — це послідовність кроків `(p, r, d)`; на кожному кроці порівнюються й обмінюються пари
`(i, i + d)` для всіх `i`, у яких `i AND p = r`. Пари одного кроку не перетинаються, тож діапазон
індексів ділиться на `k` частин, кожну обробляє окремий потік (`forkIO`), а через `MVar` потоки
чекають один одного перед наступним кроком. Масив — `IOUArray`, спільний для всіх потоків.

```bash
cabal run lab2              # масив з клавіатури або випадковий, k з клавіатури
cabal run lab2 -- bench     # заміри часу для k = 1, 2, 4, 8 (n = 1 000 000)
```

Для масивів до 16 елементів програма друкує стан масиву після кожного кроку.
Результат завжди перевіряється порівнянням із `Data.List.sort`.

Результат бенчмарку (Apple M-series, 8 ядер, n = 1 000 000, 210 кроків):

| Потоків | Час, с | Прискорення | Ефективність |
|--------:|-------:|------------:|-------------:|
| 1 | 0.313 | 1.00x | 100% |
| 2 | 0.187 | 1.67x | 83% |
| 4 | 0.100 | 3.12x | 78% |
| 8 | 0.077 | 4.06x | 51% |

Ефективність падає, бо між кроками є бар'єр синхронізації, а частина ядер — енергоефективні.

## Лабораторна №3 — обробка тексту

Типи ([Types.hs](lab3/src/Text/Types.hs)): `Symbol`, `Word`, `Punctuation`, `Token`, `Sentence`, `Text`.
[Parser.hs](lab3/src/Text/Parser.hs) замінює табуляції й послідовності пробілів одним пробілом,
розбиває текст на слова, розділові знаки та речення.

У кожному реченні перше й останнє слово міняються місцями. Розділові знаки й пробіли
залишаються на своїх позиціях, тому довжина речення не змінюється — програма це перевіряє
і виводить довжину кожного речення до і після. Речення з одного слова не змінюються.

```bash
cabal run lab3 -- lab3/data/textbook.txt result.txt
cabal run lab3              # шлях до файлу вводиться з клавіатури
```
